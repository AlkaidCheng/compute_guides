# Unix command line

The core command-line tools shared by Linux and macOS: navigating and searching
the file system, processing text, managing processes, packing archives, and
working on remote machines.

<div class="page-list" markdown>

- [Finding files](find.md)
  Count files and directories with `find`.
- [Links](links.md)
  Create, inspect and remove symbolic and hard links.
- [Permissions and groups](permissions.md)
  Read and change permissions with `chmod`, groups with `chgrp`, and defaults
  with `umask`.
- [Archives](archives.md)
  Pack and unpack directories with `tar` and `zip`.
- [SSH](ssh.md)
  Generate key pairs and install them on servers and GitHub.

</div>
